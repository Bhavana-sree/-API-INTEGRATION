# Weather App

## Overview
This is a simple Weather Application built using Python and Flask.  
The app fetches real-time weather information using a weather API and displays temperature, weather conditions, humidity, and other details in a user-friendly interface.



## Features
- Real-time weather updates
- Search weather by city name
- Temperature and humidity display
- Responsive user interface
- API integration for live weather data



## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenWeather API

## Installation

### Step 1: Clone Repository

```bash
git clone https://github.com/yourusername/weather_app.git
```

### Step 2: Open Project Folder

```bash
cd weather_app
```

### Step 3: Install Requirements

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python app.py
```



## Environment Variables

Create a `.env` file and add your API key:

```env
API_KEY=your_api_key_here
```
